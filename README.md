# Algorithm Analysis - Python

This project performs experimental analysis for sorting and Fibonacci algorithms.

## Algorithms
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Fibonacci Iterative
- Fibonacci Recursive

## Q4
The program tests different input sizes and sorted, random, and reverse-sorted conditions. It records execution time and peak memory usage.

## Run

```bash
python analysis.py
```

The generated CSV files will appear inside `results/`.

> Execution time and memory values are machine-dependent. Run the program on your own computer before submitting the final experimental results.
